The printed code outlives the file behind it.

Your QR code points to a stable address, not to a file. Replace the model with a new scan, recolour it, rescale it or move it to another plan, and the code on every printout keeps opening the current version.

If a model's access window ends, the same link shows a clear page that says so, never a dead link.
