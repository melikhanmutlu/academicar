## 2. Findings (by severity)

### Major

**M1. Development payment webhook grants a paid license to any model with no payment and no authentication**
- Route: `POST /payment/webhook/development` (`app.py:3908` `payment_webhook`), provider `DevProvider` (`payments.py:164`).
- Repro: with `PAYMENT_PROVIDER=development` (the default whenever `ALLOW_DEV_PAYMENTS` is on, i.e. every non-production deploy and any pilot that sets it), send an anonymous request:
  ```
  curl -X POST http://host/payment/webhook/development -H 'Content-Type: application/json' \
       -d '{"model_id":"<any model id>","status":"paid","plan_key":"extended_archive"}'
  ```
- Expected: rejected (no matching pending `Payment`, no signature). Actual: `200 {"ok":true}` and the model becomes Extended Archive until 2036 (verified on the project page). Server log: `payment_completed` audit rows without a prior `model_upgrade_initiated`.
- Cause: `DevProvider.verify_webhook` returns `True` unconditionally (`payments.py:174`), and the paid branch creates a brand-new `Payment` row when no existing one matches (`app.py:≈4055`, "if payment is None: payment = Payment(...)") and then calls `apply_successful_payment`. The production providers rely solely on signature verification for the same path.
- Recommendation: only grant when the event maps to an existing pending `Payment` (by `payment_id`/`provider_reference`); treat an unmatched paid event as `payment_webhook_unmapped`. Additionally make `DevProvider.verify_webhook` refuse unless `APP_ENV == "development"` or a shared secret header matches.

**M2. "Create project first, add model later" is blocked by a required Source unit field**
- Route/template: `GET /papers/new`, `templates/paper_new.html:254` (`<select name="source_unit" ... required>`).
- Repro: fill Project type, stage, title, visibility; do not attach a model; click *Save and Continue*. Nothing happens: native validation stops on the hidden-below-the-fold `source_unit` select ("Please select an item in the list"). `form.checkValidity()` lists only `source_unit`.
- Expected per the on-page copy ("You can create the publication first and upload later"): submit without a model. Screenshot `tests_runtime/qa/C_paper_new_filled.png`.
- Fix: toggle `required` on `source_unit` (and `compliance_confirm`) from the file input's `change` handler in `paper_new.html`, mirroring how the compliance box already behaves.

**M3. Terms/privacy acceptance is only enforced client-side and never stored**
- Route: `POST /auth/register` (`auth.py:186-260`). `accept_terms` appears only as an HTML `required` checkbox (`templates/register.html:48`); `RegistrationForm` has no field for it and nothing is persisted on `users`.
- Repro: remove the `required` attribute (or post the form directly) without `accept_terms` → `302 /dashboard`, "Registration successful". Compliance/KVKK-wise there is no proof of consent.
- Fix: add a `BooleanField` with `DataRequired`, store `terms_accepted_at` on `User`, log an audit row.

### Minor

**m1. Deleting a model leaves the original upload on disk.** After `POST /models/<id>/delete`, `converted/<id>/` is removed but `uploads/<id>/` (original STL/OBJ/FBX) remains. Storage leak over time; also a data-retention concern for anonymised medical data. (`model_delete`, `app.py:8580`.)

**m2. Future `access_starts_at` is not enforced.** Admin set start=2030-01-01 → `/view/<id>` still 200. `licensing.model_access_status` (`licensing.py:305-323`) checks only expiry/`license_status`. Either enforce a "not yet active" 410 state or drop the field from the admin form.

**m3. Admin license form silently downgrades on invalid input.** `POST /admin/models/<id>/license` with `license_type=bogus` → `normalize_license_type` maps it to `free` (`app.py:6134`) and saves. Should flash an error and keep the current plan.

**m4. Disabled QR link renders the generic 404 page.** `/m/<public_id>` for a QR record set to `disabled` returns "Page not found". The graceful-state rule in CLAUDE.md suggests an explicit "link disabled by administrator" page (like `model_access_unavailable.html`).

**m5. "R2 mirror retried successfully" flash when no mirror is configured.** `POST /admin/models/<id>/mirror/retry` reports success although `R2_*` env is unset. Should say "mirror not configured".

**m6. Email-change confirmation with a bad token returns a bare 404.** `/account/email/confirm/badtoken` → 404 page instead of flash + redirect to `/profile` (the password-reset equivalent does it right).

### UX / design

**U1. Expired-model page CTA is not owner-aware.** "View upgrade options" links to `/pricing`; for the logged-in owner it should deep-link to `/models/<id>/upgrade`. (`model_access_unavailable.html`, screenshot `H_expired_viewer_owner.png`.)

**U2. Viewer modals ignore Escape.** QR modal, Info panel and annotate mode do not close on `Esc`; the QR modal also offers no download/print link (only the image). Keyboard users must find the × button. (`templates/viewer.html` `#qrModal`, `#infoPanel`, `#annotateHint`.)

**U3. Coupon helper text hardcodes PayTR.** `model_upgrade.html`: "The code is validated before PayTR opens…" is shown for every provider (dev/LemonSqueezy). Also "Continue to payment … You'll be taken to a secure payment page" is shown with the dev provider, which grants instantly.

**U4. Model-edit "Access plan" card truncates values at desktop width** ("Free Acc…", "Until Sep…", screenshot `D_model_edit.png`). Widen the two stat boxes or let them wrap.

**U5. Dashboard rows show a literal "-" when a project has no description** (`D_dashboard.png`). Hide the line instead.

**U6. Free-plan capacity notice replaces the whole upload panel** after the first model ("Plan capacity reached 1/1"). Good conversion moment, but the copy "ask an administrator to raise this limit" is confusing for self-serve researchers; point to *Upgrade* or *New project* instead.

**U7. `/admin/ar-doctor` returns raw JSON** with no layout; fine for ops, but it is linked from the admin sidebar as a page.

**U8. Admin mobile tables**: the header, filters and stat cards of every admin page stack cleanly at 390 px and no page scrolls horizontally, but the wide data tables (revenue, audit log, users) were only checked for overflow, not for readability; verify column priority on a real phone and consider hiding low-priority columns under 640 px.

**U9. Suspended institution keeps a live public showcase** (`/i/<slug>` still 200 after `status=suspended`). Consider a "temporarily unavailable" state.

**U10. Rate limit copy** ("Too many attempts in a short time…") is shown twice when both the per-minute and per-hour limits trip on the same request (`B_register_dup.png`).

**U11. Landing hero and viewer have hard external dependencies with no fallback** (Tailwind Play CDN, `unpkg` model-viewer 4.3.0, `gstatic` Draco decoder). When any is unreachable the hero is blank and Draco-compressed models (every optimised upload) never render. Tailwind Play CDN is also not recommended for production (runtime JIT, FOUC, `unsafe-eval` in CSP — `app.py:114`). Vendor the assets into `static/vendor/` and set `ModelViewerElement.dracoDecoderLocation`.

**U12. Registration email validator rejects `.test`/`example.*` domains** ("Invalid email address") — fine for production, but the error message does not say why. Cosmetic.

**U13. Annotate mode has two exits (Done pill, Annotate→Cancel button) but no `Esc`**, and the video-recording status keeps running while annotating; consider pausing recording when a modal/form opens.

**U14. FBX → GLB output is larger than the source** (Tree.fbx 4.4 MB → 6.6 MB GLB). `finalize_converted_glb()` ran (Draco + webp) but textures dominate; consider a max texture size for the AR copy.

**U15. Full-page screenshots show the sticky header repeating mid-page** — capture artifact only, no action.

**U16. Paper-new form: hidden `authors`/`year` inputs** are only filled by the DOI/PMID fetch; manual authors entry lives inside the "Articles about this topic" block, which is not obvious for a thesis without a DOI.

**U17. `/institution/showcase-settings` is POST-only** (405 on GET) while the panel has a `showcase.html` template; harmless but the URL is guessable from the nav.

## 6. Top 10 UX improvements (priority order)

1. Make `source_unit`/consent required only when a model file is selected (M2) — first-run users cannot create an empty project today.
2. Owner-aware CTA on the expired page → `/models/<id>/upgrade` (U1) — this is the renewal moment.
3. Vendor Tailwind (build step), model-viewer and the Draco decoder locally (U11) — removes the blank-hero/blank-viewer failure mode and tightens CSP.
4. `Esc` closes every viewer overlay; QR modal gets Download/Print links (U2).
5. Provider-agnostic upgrade copy; hide "secure payment page" text for the dev provider (U3).
6. Rephrase the free-plan capacity notice toward *Upgrade this model* / *Start another project* (U6).
7. Explicit "link disabled" resolver page and "institution suspended" showcase state (m4, U9).
8. Fix stat-box truncation on the model-edit page and hide empty description dashes (U4, U5).
9. Column priority for wide admin tables on phones (U8).
10. Style `/admin/ar-doctor` like the other admin pages or move it under System health (U7).
